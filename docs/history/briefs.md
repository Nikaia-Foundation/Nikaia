# Briefs of finished lanes

The briefs, reports and run files of the lanes that are finished (the old main
lane, the `b`, `m`, `p`, `k`, `c`, `e`, `s`, `t`, `r`, `gr`, `bt`, `mf` and
`lane-*` series, and the areas `prover` and `docs`) left `docs/briefs/` on
2026-11-05. `docs/briefs/` holds only what a running lane needs.

They are still in git, at the commit before they left:

```
git show aa297794:docs/briefs/<name>
git ls-tree --name-only aa297794 docs/briefs/
```

What a lane found and decided is on its issue and in the ADRs; the brief was
only the order.
