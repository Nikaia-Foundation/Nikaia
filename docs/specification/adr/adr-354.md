# ADR-354: An Element or a Field Read off a Place Is a View Where a `ref T` Is Declared, and a Word Is Not

**Status:** Accepted
**Date:** October 14, 2026
**Answers:** whether `given[0]`, over a `given: ref Vec[Expr]`, may be bound
as a `ref Expr`
**Related:**
[ADR-094](adr-094.md) D4 (a `let` over a place is a view of it);
[ADR-279](adr-279.md) D8 (a word by its kind is copied at a read, every other
type is lent, at every size), D10 (a borrowed left side beside a jump is a view);
Part I 6.5; Part III C.1 (`NK1103`, `NK1257`)

## 1. Question

A `let` over a place is already a view of it (ADR-094 D4): `let y = given[0]`
lends the element. Written with its type, `let y: ref Expr = given[0]`, the
same read was refused with `NK1103`, *this value is `Expr`*, and so was the
same read as one arm of `let x: ref Expr? = if c { tail } else { given[0] }`.
The read was typed as the element itself, and a fit compares the view flag
strictly. The written type says what the untyped `let` already does.

## 2. How others do it

Rust writes the borrow, `&given[0]`, and a `&T` slot takes it. C++ binds a
`const T&` to an element without a mark. Swift and Kotlin have no view type
to write. None of them copies a large value because a reference was declared.

## 3. Decisions

### D1 — An index or a field read off a place is a view where the slot declares `ref T` or `ref T?`, and `T` is not a word.

`let y: ref Expr = given[0]` and an arm `given[0]` under `ref Expr?` are views
of the element, lowered with `&`. A view kept past the loan is refused as any
view is (ADR-279 D11).

### D2 — A word by its kind, written as a word type, is refused: `NK1257`.

A number, a `bool`, a `scalar` and an enum whose variants hold nothing are
copied at a read (ADR-279 D8), so `let y: ref i64 = given[0]` declares a view
that does not exist. The help writes the `let` without the type:
*an `i64` is copied at a read; write `let y = given[0]`*. ADR-279 D8 stands.

### D3 — Inside generic code a `ref T` is accepted, whatever `T` becomes.

A body over `T` cannot know that `T` will be a word; the read is lent there,
and where `T` turns out to be `i64` it is a view of a number, which is still
correct.

## 4. Rejected

* **B — refuse `ref` in a `let`'s annotation.** A view is a type the
  language writes everywhere else; a `let` saying what it already does is no
  reason for a refusal.
* **C — leave it as it is.** The untyped `let` lends and the typed one is
  refused: the annotation would change what the read is.
