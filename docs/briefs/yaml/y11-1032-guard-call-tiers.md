## Issue (#1032, copied)

Found by the `yaml` lane (y2c, #928 step 2b, 2026-10-31): the y2 draft's `fits_node` guards. A compiler defect, fixed in the compiler (CLAUDE.md).

### Probe (the architect ran it on 506edc2d)

```nika
grammar G {
	rule WS = "" -> { }
	rule Word -> i64 = x:any if(x >= 'a' && x <= 'z') -> { 1 }
	entry rule top -> String = s:text(Word+) if(fits(s), "too short") eof -> { s }
}
fn ok(s: String) -> bool sync {
	let body = s.strip_prefix("-") ?? s
	return body.len() > 1
}
fn fits(s: String) -> bool sync {
	return ok(s)
}
fn other(s: String) -> bool sync {
	return ok(s)
}
fn main() {
	let r = G::top("abc") catch {
		println("error")
		return
	}
	println(r)
	println(other(r))
}
```

`nikaia run`: NK1185 at the `??` in `ok` (left a view, fallback `String`). The same with the call moved into the action (`eof -> { if fits(s) { s } else { s } }`) prints `abc`, `true`; so does an unused `fits` with no `other`.

### Cause (architect, by reading; the probe agrees)

`bind_grammar_pattern` (`crates/nikaia-std/src/tools/text_tiers.nika:5236`, called from `walk_grammar:5191`) walks labels, sequences, choices, refs, repeats and groups, and drops everything else in `else => {}`: a `Pattern::Guard { cond, .. }`'s expression is never handed to `tier_expr`, so `fits(s)` is no call site and `fits`' parameter (and through it `ok`'s) is tiered from the other callers only. The same `else` drops a rule call's value arguments and a counted repeat's bounds (unverified whether they matter).
