### Probe (the architect ran it on 506edc2d)

```nika
grammar G {
	rule WS = "" -> { }
	rule Ch -> i64 = x:any if(x >= '0' && x <= '9') -> { 1 }
	entry rule top -> String = s:text(d:Ch+) if(s.len() > 1, "two digits") eof -> { s }
}
fn main() {
	let r = G::top("12") catch {
		println("error")
		return
	}
	println(r)
	let e = G::top("1") catch {
		println("error")
		return
	}
	println(e)
}
```

`nikaia check` passes; `nikaia run` fails in rustc: `Cannot find value s` (4:43). Without the inner label, `s:text(Ch+)`, it prints `12`, `error`.

### Cause (architect, from `nikaia lower`)

A `text(..)` whose pattern binds names (#1013) is lowered as `(d:Ch+) @ __nikaia_s_from`, and `s` itself is bound only in the action's prelude (`emit_grammar.nika:393-401`, `let s = ::nikaia_std::grammar::covered(input, __nikaia_s_from.start..__nikaia_s_from.end);`). The guard is emitted inside the pattern (`emit_pattern.nika:153`, `Pattern::Guard`), before the action, where only `__nikaia_s_from`/`_to` exist. Lowered line: `(d:Ch+) @ __nikaia_s_from if(s.len() > 1, "two digits") eof`.
