Pre-alpha: what to expect

The problem
A new language is easy to promise and hard to use. You should know where it stands before you start.
An example
Try the examples: a calculator, a JSON parser, a log analyser, a small HTTP server, the One Billion Row Challenge.
What Nikaia checks
The compiler builds real programs today: a calculator, a JSON parser, a log analyser, a small HTTP server, the One Billion Row Challenge. There is no package registry, formatter or language server yet. The roadmap lists what works, the walls you will hit, and where a bug report helps most.
The limit
Pre-alpha means walls: things that do not work yet, and rules that will still change. The roadmap lists them.
