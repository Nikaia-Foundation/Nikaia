Built in the open

The problem
A language that asks you to trust it should show how it was made.
An example
Why does assert become a contract? The answer is an ADR, with the options that were rejected.
What Nikaia checks
Every design decision is a public ADR with the evidence that settled it. Every change has one entry in the changelog. The compiler is moving into Nikaia: the analyses for sharing, pausing, what a function throws and which statements may overlap are already Nikaia code.
The limit
The figures below are dated. The changelog and the repository are the current record.
